# Team brief template

Copy this template for a new employee agent team. Fill in every field before the first job.

## Team

- Chief of staff: name, job, and what it decides
- Specialist bot 1: name, one job, inputs, deliverable, stop point
- Specialist bot 2: name, one job, inputs, deliverable, stop point
- Specialist bot 3: name, one job, inputs, deliverable, stop point

## Shared setup

- Notes and files the team reads first
- Browser sessions to sign in once on the cloud computer
- Tools and logins each bot may use
- Tools and logins each bot must not use

## Job brief

- Outcome
- Sources
- Constraints
- Deliverable
- Review point where a bot must stop and ask the user

## Routine

- Skill name, if the job worked two or three times
- Schedule, if the skill becomes a routine
- Owner and last hand run date
