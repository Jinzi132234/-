## 2. A-roll vs B-roll vs 混合

| 类型 | 画面 | 叠加物 | 用途 |
|------|------|--------|------|
| **A-roll** | 真人说话脸（办公室实景 + 紫色环境光） | 稀疏：一侧厚奶油卡、动能字、编号行、偶发小胶囊；**绝不挡脸** | 观点、转场口、收尾 |
| **B-roll / 空镜舞台** | 无人脸，全屏饱和渐变舞台或近黑产品 UI | 厚卡、字母贴纸、mac 窗、进度条、扇形窗、流程图、站点 UI | 概念、产品实操、列表、对比 |
| **混合** | Lesson board：蓝→青外框 + 厚白/奶油圆角板 + **左下圆角 PiP**；或产品窗 + 角 PiP（可黄/绿描边） | 板上 1 标题 + 流程图/1–6 卡/步骤条 | 课程主讲板、长实操旁白 |

硬规则：叠加只落负空间；A 稀、B 满；实操段优先终端/Agent Dock/Photos UI，不是 PPT 列表墙。

## 3. 锁定视觉语法（对标实测 · 勿软化）

### 色板（必须对齐，禁止软 pastel）
- **全屏舞台轮换（饱和满幅）**：terracotta / emerald / cobalt / violet / hot pink / cream / navy / peach（含 mustard-gold 过渡洗，如 f_038）
- **贴纸六色（可反复）**：blue / pink / gold / green / purple / orange
- **中性**：cream / off-white 厚卡；near-black / charcoal mac·终端窗
- **点题一词**：gold 或 coral/terracotta 打点
- **Lesson board**：blue→teal 渐变外框 + 厚白/奶油圆角板（板上可再铺 emerald / terracotta 内舞台，见 f_069–070）
- **禁**：软桃/软青/软紫淡 pastel 当默认舞台；自造主题色；无意义彩虹堆色

### 组件（轮换英雄语言）
1. **厚奶油卡**（无边或薄白边、大圆角、厚阴影；可两段式饱和顶+奶油身；可微倾）
2. **动能字 / word slam**（大字叠脸负空间或舞台；一词打点）
3. **macOS / 近黑产品窗**（红绿灯、标题珊瑚星号、橙描边输入、窗内 pill 仅作 UI）
4. **编号圆盘 / 字母贴纸方砖**（贴纸六色）
5. **进度模块 / 分步条 / 对勾清单**（粉边 Working、绿 Done）
6. **扇形/层叠 cream mac 窗**（粉叙事 f_044）
7. **流程图节点**（星号→MOD 雷达→窗；虚线连接）
8. **聊天气泡 / 引用奶油卡**（Claude 失败卡等）
9. **黑/饱和胶囊** — **仅次要**：kicker、状态、outro CTA；不得作每板默认主语言

字体感：Inter / SF，粗体；大写标签若用胶囊则保持次要。

### 动感（*inferred* + 语法库）
- 字块 / 字母贴纸约 **0.3s** 错峰弹入；末张可微倾落定
- 卡：自上而下或自侧叠入后锁网格
- UI：打字、进度填充、绿 Done / 粉 Working 弹出；模态 spring 盖在 mac 上
- Filmstrip / 扇形窗横向或对角错位展开
- 霓虹竖分割线切开分屏（黄/绿）
- **几乎无运镜**；硬切为主，非慢溶解

## 4. 版式节奏（对标循环）

1. **全脸稀疏 → 硬切全舞台 → 回脸**
2. **Lesson board + 左下 PiP**（主课程板；板上内容每次换）
3. **左右对切**：脸 | 一张大卡 / mac / 终端（偶有霓虹竖线）
4. **全舞台动能字 / 倾斜字母贴纸 / 超大倾斜卡**
5. **全舞台 mac + 侧卡 + 虚线连接 / 流程图**
6. **全脸 + 左 1/3 厚奶油卡**（可叠第二张 + 编号逐行）
7. **粉/彩叙事舞台**：引用卡 → 扇形多窗
8. **长段产品 B-roll**：终端进度、Agent Dock、Photos±角 PiP、赞助站点
9. **收束**：超大倾斜奶油卡（如 $0）+ 可选一颗次要黑胶囊；片尾多 CTA

一条口播：**一 idea 一舞台**；标题 + 1–6 元素，留白要多。

推荐节拍（可循环，勿每段抄死）：
- `稀疏全脸 → Stage+PiP → 对切 → 变化收尾`
- `脸 → 动能字板 → 脸+单厚卡`
- `脸 → 深色 UI 舞台 → 脸+聊天气泡/引用卡`
- `脸 → 粉叙事卡 → 扇形窗 → 回脸`
- `产品长镜（终端/Dock/Photos）± 角 PiP → 回脸强调卡`

## 5. 「不要重复」尺度（2026-10-15 全片密帧校准）

| 层 | 重复程度 | 规则 |
|----|----------|------|
| **色板 / 组件家族** | 高重复 OK | 奶油卡、mac 窗、贴纸六色、进度 UI、Lesson 外框可反复；**黑胶囊可出现但勿当唯一英雄** |
| **舞台主色** | 中偏松 | **同一 idea 弧内**可连用同主色 2–3 刀（钴蓝产品卡、粉失败叙事、翠绿安装）；idea 换了再换主色 |
| **版式（Layout）** | **中重复 OK** | Split、Lesson+PiP、全舞台、产品 UI 是主循环；同 idea 可连刀同家族（1→2 卡、粉卡→扇窗、Photos 步骤累加）；**换 idea 优先换版式**；禁整课锁死一种 |
| **主叠加语言** | **中–低** | 相邻 idea **优先换英雄语言**（卡 ↔ 动能字 ↔ mac ↔ 贴纸 ↔ 进度 ↔ 气泡）；勿连续多板「黑胶囊+一行字」 |
| **图标 / 贴纸形态** | 极低 | **每一刀换一套 Mark** |
| **入场动效轴** | 极低 | **每一新 idea 换主 M 轴**；同 idea 多刀可共用轴但换内容 |
| **收尾处理** | 低–极低 | **连续两段禁止同一 E**；双下胶囊强调 **正片最多 1 次**；**片尾 outro 允许多 CTA 一次** |

### 全片频次（密帧约数，见 FRAME-CATALOG）
- **Split 脸\|卡/UI**：最密（~20/75）
- **纯产品 UI 长镜**：极密中后段（~22/75）— 一等公民
- **Lesson+PiP**：约 **6** 次回访，板上 Mark/结构必换
- **全脸+侧奶油卡**：中段强调多次
- **粉叙事连刀**：有证据（f_043–044）
- **Outro**：Thanks + Sponsor + Comment + Like **整片一次**（f_075）

**写给 Claude 前自检：**
1. 新 idea？→ 新 M 轴 + 新 I 套 + 换英雄叠加语言  
2. 同 idea 连刀？→ 可同版式/同色，内容必须推进  
3. 新 E？（正片勿连用双胶囊）  
4. 没挡脸？没默认黑胶囊英雄？  
5. 仍在锁定饱和色板（非软 pastel）？  
6. 不像 PPT？
