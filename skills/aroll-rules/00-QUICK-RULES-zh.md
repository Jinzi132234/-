# A-ROLL 一頁速查

## 定位
真人說話臉是英雄。疊加 **只允許字卡 / UI**；禁止在 A-roll 裡畫插畫 B-roll 場景。

## 版式家族（輪換，勿每板默認 Split）
1. **Sparse 全臉** — 肩 / 左下負空間 **只 1 枚** 奶油章
2. **Lesson + PiP** — 多 UI 在板上，臉在角 PiP
3. **Stage + 角 PiP** — 多 UI 在舞台，臉在角
4. **Split** — 臉 | 右欄 UI

多元素 UI（芯片、路徑卡、對比、編號）**必須**硬切到 2/3/4；**禁止**堆在胸口（plate-151 禁令）。
