# 动效规则重校 · 给用户的短摘要

依据：你发的整支对标视频（≈10 分钟）+ 75 张密帧全目检（约每 8 秒一帧）。未做逐帧播放；动效节奏为静帧推断。

## (a) 系统一句话

厚奶油卡 / 动能字 / 近黑 mac·产品窗 / 彩贴纸 / 进度 UI 轮换作主画面；饱和舞台硬切 spring；**黑胶囊只作次要点题，禁止每板默认药丸。**

## (b) A vs B vs 混合

| | 画面 | 叠加 |
|--|------|------|
| **A** | 说话脸 | 稀：侧奶油卡、动能字、编号行；不挡脸 |
| **B** | 无人脸全舞台或产品 UI | 满：卡、窗、贴纸、进度、扇窗、流程 |
| **混合** | Lesson 蓝青板+左下 PiP，或产品窗+角 PiP | 板上标题+流程/步骤 |

## (c) 锁定色板（勿改成软 pastel）

舞台：陶土橙 / 翠绿 / 钴蓝 / 紫 / 热粉 / 奶油 / 海军蓝 / 桃  
贴纸六色：蓝粉金绿紫橙  
Lesson：蓝→青外框 + 厚白奶油板；窗用近黑

## (d) 叠加轮换（反胶囊默认）

主语言轮换：**奶油厚卡、动能字、mac/终端窗、编号盘、字母砖、气泡/引用卡、印章、层叠窗、进度模块**。  
黑/彩胶囊：kicker、状态、片尾 CTA —— **次要**。

## (e) 不重复表（简）

| 层 | 尺度 |
|----|------|
| 色板/组件家族 | 可高重复 |
| 舞台主色 | idea 内可连 2–3 刀同色 |
| 版式 | 中重复；换 idea 再换版式 |
| **主叠加语言** | 相邻 idea 优先换 |
| 图标形态 / 动效轴 / 收尾 E | 极低重复；正片勿连用双胶囊；片尾多 CTA 仅一次 |

## (f) 推荐节拍

`稀脸 → Lesson+PiP → 对切 → 变收尾`
